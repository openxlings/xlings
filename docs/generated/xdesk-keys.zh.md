# xdesk 的快捷键

<!-- 由 `xdesk --keys-markdown zh` 生成，请勿手改。键位测试在 XDESK_KEYS_WRITE=1 时重写它。 -->

单按 Super：应用。按住 Super 一秒：最常用的键。

| 分组 | 操作 | 键 |
|---|---|---|
| 找 | 应用 | `Super+Space` |
|  | 按应用切换 | `Super+Tab`, `Super+Shift+Tab` |
|  | 同一应用的窗口间切换 | `` Super+` ``, `` Super+Shift+` `` |
|  | 按窗口切换（空间总览） | `Alt+Tab`, `Alt+Shift+Tab` |
|  | WuXian 视图（无限画布）/ 返回 | `Super+O` |
| 焦点与移动 | 焦点向左 | `Super+Left`, `Super+H` |
|  | 焦点向右 | `Super+Right`, `Super+L` |
|  | 焦点向上 | `Super+Up`, `Super+K` |
|  | 焦点向下 | `Super+Down`, `Super+J` |
|  | 左移（层叠：左半屏） | `Super+Shift+Left`, `Super+Shift+H` |
|  | 右移（层叠：右半屏） | `Super+Shift+Right`, `Super+Shift+L` |
|  | 上移（层叠：上半、全屏） | `Super+Shift+Up`, `Super+Shift+K` |
|  | 下移（层叠：下半、还原） | `Super+Shift+Down`, `Super+Shift+J` |
|  | 并进左边一列（组） | `Super+[` |
|  | 拆出成单独一列 | `Super+]` |
| 窗口 | 最大化 / 还原 | `Super+F` |
|  | 全屏 / 退出全屏 | `Super+Shift+F` |
|  | 浮动 / 放回 | `Super+Shift+Space` |
|  | 置顶 | `Super+P` |
|  | 在所有工作区显示 | `Super+Shift+P` |
|  | 关闭窗口 | `Super+Q`, `Alt+F4` |
|  | 复制（终端里也可以） | `Super+C` |
|  | 粘贴（终端里也可以） | `Super+V` |
| 大小 | 列宽：1/3、1/2、2/3、全宽 | `Super+R` |
|  | 列内高度：平分、2/3、1/3 | `Super+Shift+R` |
|  | 变窄（WuXian 视图：缩小） | `Super+-` |
|  | 变宽（WuXian 视图：放大） | `Super+=`, `Super+Shift+Plus` |
|  | 平分（WuXian 视图：回到 100% 并居中） | `Super+0` |
|  | WuXian 视图：显示全部 | `Super+Ctrl+0` |
| 排布 | 工作区的规则：平铺或层叠 | `Super+M` |
| 工作区 | 工作区 1 | `Super+1` |
|  | 工作区 2 | `Super+2` |
|  | 工作区 3 | `Super+3` |
|  | 工作区 4 | `Super+4` |
|  | 工作区 5 | `Super+5` |
|  | 工作区 6 | `Super+6` |
|  | 工作区 7 | `Super+7` |
|  | 工作区 8 | `Super+8` |
|  | 工作区 9 | `Super+9` |
|  | 移到工作区 1 | `Super+Shift+1` |
|  | 移到工作区 2 | `Super+Shift+2` |
|  | 移到工作区 3 | `Super+Shift+3` |
|  | 移到工作区 4 | `Super+Shift+4` |
|  | 移到工作区 5 | `Super+Shift+5` |
|  | 移到工作区 6 | `Super+Shift+6` |
|  | 移到工作区 7 | `Super+Shift+7` |
|  | 移到工作区 8 | `Super+Shift+8` |
|  | 移到工作区 9 | `Super+Shift+9` |
|  | 放到 WuXian 上（自由窗口） | `Super+Shift+0` |
|  | 新建工作区 | `Super+Ctrl+N` |
|  | 上一个工作区 | `Super+Ctrl+Left`, `Super+PageUp` |
|  | 下一个工作区 | `Super+Ctrl+Right`, `Super+PageDown` |
|  | 带着窗口去上一个工作区 | `Super+Ctrl+Shift+Left`, `Super+Shift+PageUp` |
|  | 带着窗口去下一个工作区 | `Super+Ctrl+Shift+Right`, `Super+Shift+PageDown` |
| 打开 | 终端 | `Super+Enter`, `Ctrl+Alt+T` |
|  | 设置 | `Super+I` |
|  | 快捷键 | `Super+/` |
