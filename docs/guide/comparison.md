# 与其他工具对比

> 更新日期: 2026-09-26 | 版本: 2026.9.26.3

xlings 与常见工具的定位对比:

| | apt / brew | nix | docker | **xlings** |
|---|:---:|:---:|:---:|:---:|
| 多版本共存 | 不支持 | 支持 | 支持 | 支持 |
| 无需 Root | 不支持 | 部分场景 | 部分场景 | 支持（image 模式除外） |
| 无 daemon | 支持 | 支持 | 不支持 | 支持 |
| 跨平台统一命令 | 不支持 | 部分场景 | 支持 | 支持 Linux / macOS / Windows |
| 隔离粒度 | 不支持 | 文件系统 | 文件系统 | shell / FS / image 三级 |
| 存储复用 | — | store | 镜像膨胀 | 版本视图 + 引用计数 |
| 去中心化索引 | 不支持 | 不支持 | 不支持 | 官方 + 第三方 + 自建 |
| Agent / JSON 接口 | 不支持 | 不支持 | API | `xlings interface`（NDJSON） |
| 可作 OS 级包管理器 | apt 本身是 | NixOS | 不支持 | 支持（Luban Linux，规划中） |
