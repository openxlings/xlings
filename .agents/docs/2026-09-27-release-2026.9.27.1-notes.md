# 2026.9.27.1 发布说明

> 相关：xlings#620（配方打包修订号）、#621（glibc 的 locale 与 gconv）；libxpkg 0.0.58；xim-pkgindex#892。
> 本文记录本版的变化与客户端可见的差异；发布后的验证结果追加在 §3。

## 1. 变化

| 项 | 内容 |
|---|---|
| 打包修订号 | 版本条目可写 `revision`（libxpkg 0.0.58 解析）。载荷的安装记录 `.xpkg-install.json` 写入修订号；记录的修订号低于配方时视为未安装，`install` 就地重装，并输出 `recipe revision <n>, installed revision <m>` |
| 就地重装 | 旧载荷先移入 `<data>/stale/`，新载荷装到原路径；成功后删除旧载荷，失败时移回。配方会把 `install_dir()` 写进所装文件，因此不能先装到临时目录再改名 |
| 中断恢复 | 移出旧载荷之前，在其旁写入标记 `<parked>.origin`（原路径与所属进程，原子写入）。每条 `install` 命令开始时处理 `<data>/stale/`：所属进程已不存在的条目，原路径缺失或为空占位时移回，否则连同标记删除；进程仍存活的条目不动。进程内的析构回滚保持不变 |
| `install_targets` 事件 | 接口协议 1.1：顶层安装在所有路径上报告每个请求解析到的命名空间、名称、版本、修订号、状态与载荷目录。mcpp 2026.9.27.1 优先读取这一记录 |
| 版本选择一致性向量 | `tests/data/semver-vectors.tsv` 由单元测试驱动；mcpp 以同一份向量测试其版本选择 |
| 重命名失败的提示 | Windows 上目录中的文件被占用而无法移动时，提示点名被占用的文件 |

## 2. 客户端可见的差异

- `install_summary.success` 只计本次实际安装的数量；已是当前修订的载荷报告为 `already_present`，不计入。
- 旧版 xlings 忽略 `revision`：持有旧载荷的机器要升级到本版后才会重装。

## 3. 发布后验证

| 步骤 | 结果 |
|---|---|
| PR CI（linux / linux-e2e / linux-root / macos / windows / aarch64） | #622 在 `8fb9a43` 上全绿。第一轮 Windows 失败：新增的单元测试在删除临时目录时，读取安装记录的文件流仍未关闭，改为在独立作用域内读取 |

| 索引 bump | 机器人开出 openxlings/xim-pkgindex#893，4 个平台的 sha256 与 sidecar 逐一核对后合并；Publish Index Artifact 成功 |

### 3.1 真机验证（Linux，mirror=CN）

在 subos `eco-0927` 中 `xlings update`、`xlings install xlings@2026.9.27.1`、`xlings use xlings 2026.9.27.1`。subos 与宿主共享 `~/.xlings`，因此入口程序随之切换：

```
xlings 2026.9.27.1
symlink shims (default subos): 326, not resolving to the entry: 0
```

### 3.2 #620、#621（沙箱，隔离的 XLINGS_HOME）

`xlings subos use eco-0927 --sandbox --cmd ...`：

1. 全新 `xlings install glibc@2.44.3`，安装记录为 `"revision": 1`；
2. 载荷自带的 `locale -a` 列出 `C.utf8`，UTF-8 的"中"经载荷的 gconv 转为 GBK `d6 d0`；
3. 把安装记录改为 revision 0（模拟修复之前安装的载荷）后再次 `install`：输出 `recipe revision 1, installed revision 0`，完成重装，记录恢复为 revision 1，`<data>/stale/` 为空；重装后的载荷仍列出 `C.utf8`。

#620 已据此评论并关闭。
