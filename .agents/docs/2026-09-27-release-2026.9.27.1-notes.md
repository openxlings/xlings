# 2026.9.27.1 发布说明

> 相关：xlings#620（配方打包修订号）、#621（glibc 的 locale 与 gconv）；libxpkg 0.0.58；xim-pkgindex#892。
> 本文记录本版的变化与客户端可见的差异；发布后的验证结果追加在 §3。

## 1. 变化

| 项 | 内容 |
|---|---|
| 打包修订号 | 版本条目可写 `revision`（libxpkg 0.0.58 解析）。载荷的安装记录 `.xpkg-install.json` 写入修订号；记录的修订号低于配方时视为未安装，`install` 就地重装，并输出 `recipe revision <n>, installed revision <m>` |
| 就地重装 | 旧载荷先移入 `<data>/stale/`，新载荷装到原路径；成功后删除旧载荷，失败时移回。配方会把 `install_dir()` 写进所装文件，因此不能先装到临时目录再改名 |
| 中断恢复 | 移出旧载荷之前，在其旁写入标记 `<parked>.origin`（原路径与所属进程，原子写入）。每条 `install` 命令开始时处理 `<data>/stale/`：所属进程已不存在的条目，原路径缺失或为空占位时移回，否则连同标记删除；进程仍存活的条目不动。进程内的析构回滚保持不变 |
| `install_targets` 事件 | 接口协议 1.1：顶层安装在所有路径上报告每个请求解析到的命名空间、名称、版本、修订号、状态与载荷目录。mcpp 2026.9.27.1 优先读取这一记录 |
| 版本选择一致性向量 | `tests/data/semver-vectors.tsv` 由单元测试驱动；mcpp 以同一份向量测试其版本选择 |
| 重命名失败的提示 | Windows 上目录中的文件被占用而无法移动时，提示点名被占用的文件 |

## 2. 客户端可见的差异

- `install_summary.success` 只计本次实际安装的数量；已是当前修订的载荷报告为 `already_present`，不计入。
- 旧版 xlings 忽略 `revision`：持有旧载荷的机器要升级到本版后才会重装。
